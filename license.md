## Recommended License: MIT License

`mdir-cli` is a standalone macOS command-line tool distributed as source and prebuilt binaries. For this kind of developer utility, the MIT License is the best fit because it:

- keeps adoption friction low for individual users, companies, and package managers such as Homebrew
- allows modification, redistribution, and commercial use without imposing copyleft obligations
- stays short and easy to understand for a small single-binary project
- matches common practice for small CLI utilities and Swift open source projects

Apache-2.0 would also be reasonable, but its extra patent and notice machinery is usually unnecessary overhead for a compact local file manager like this one. GPL-family licenses would reduce downstream adoption and packaging flexibility without a clear project-specific need.
