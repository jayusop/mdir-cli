# Changelog

## 1.0.0 - 2026-05-04

- Initial public release of `mdir`
- DOS-style detailed directory listing for macOS
- Wide, bare, recursive, tree, and no-color output modes
- Hidden/file/directory filtering and name/size/date sorting
- Wildcard pattern support such as `*.swift` and `Sources/*.swift`
- Full-path output and built-in help output
- Install, uninstall, smoke test, release packaging, and Homebrew formula helper scripts
